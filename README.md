# 机器学习课程设计

《机器学习》课程设计包含四个 Kaggle 任务：植物幼苗分类、人脸表情识别、眼底黄斑中心凹定位、视网膜血管分割。四个任务各写成一章，本仓库按任务保存代码、配置、训练日志与最终提交文件，便于复查和复现。

课程设计报告：`机器学习课程设计报告_祁震淼_20245627.pdf`，提交包内只放这一份 PDF；`.docx` 为编辑用工作版本。

## 四个任务

### 任务一 植物幼苗分类

- 数据：训练 500 张（5 类，每类 100 张），测试 378 张，评价指标 Micro F1。
- 方法：ConvNeXt、Swin、EfficientNet 三类骨干，5 批共 15 个模型；弱增强；5 折交叉验证；D4 八向 TTA；贪心加权融合。
- 本地结果：OOF Micro F1 0.9600，嵌套交叉验证 0.9520。
- 平台结果：公榜 0.9708（20/80），私榜 0.9708（20/80）。
- 代码：[task1/](task1/)

### 任务二 人脸表情识别

- 数据：训练 28,275 张，测试 7,065 张，48×48 灰度图，6 类，评价指标准确率。
- 方法：多架构成员池；伪标签迭代；对数概率空间贪心加权、连续权重搜索与类别偏置校准；近重复校正。
- 本地结果：5 折 OOF 准确率 0.7417，最强单模型 0.7191。
- 平台结果：公榜 0.749（11/74），私榜 0.749（11/74）。
- 代码：[task2/](task2/)

### 任务三 黄斑中心凹定位

- 数据：训练 80 张（附 XML 框标注），测试 20 张，评价指标坐标 RMSE。
- 方法：ResNet18 + FPN 热图回归；空间 softmax 交叉熵配 soft-argmax 坐标损失；视盘锚点通道；512/384 多尺度推理；7 个模型坐标中位数集成。
- 本地结果：5 折 OOF RMSE 19.67 像素，多尺度后 18.87 像素。
- 平台结果：公榜 11.59175（28/78），私榜 19.90697（29/78）。
- 代码：[task3/](task3/)

### 任务四 视网膜血管分割

- 数据：训练 20 张，测试 20 张，评价指标 Dice，提交格式为 RLE。
- 方法：4 层 U-Net；BCE + soft Dice；5 折交叉验证；8 变换 TTA；级联精修器；按官方脚本规则编码。
- 本地结果：OOF 512-Dice 0.8453，级联精修后 0.8466。
- 平台结果：公榜 0.85737（23/75），私榜 0.85936（22/75）。
- 代码：[task4/](task4/)

## 环境

任务一、任务二在 Kaggle Notebook 上训练，GPU 为 Tesla T4 或 P100，PyTorch 2.x + CUDA。

任务三、任务四在本机 Linux x86_64 上运行，16 核 CPU、14 GB 内存，PyTorch 2.14.1（CPU 版）。Python 3.13.9，timm 1.0.30，scikit-learn 1.7.2，OpenCV 5.0.0。主要依赖：

```
torch torchvision timm
numpy pandas scikit-learn
opencv-python pillow
kaggle
```

## 数据与权重

仓库只保留能够用纯文本或小体积数组表达的部分：配置、日志、指标、折外概率与最终提交文件。原始图像、模型权重与中间缓存不入库，运行前需要按各任务 README 的说明把数据放回对应目录。

## 复现方式

每个任务的 README 给出完整的命令序列。整体流程一致：先放好数据，训练若干模型，再按融合脚本生成提交。融合步骤可以在只读日志和已保存概率的前提下单独重跑，例如：

```bash
cd task1
python3 code/02_融合/reproduce.py --verify
```

比赛结束后训练与推理代码保持不变，仓库只补充说明文档与结果记录。
