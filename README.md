## 任务

- **task1 植物幼苗分类**：ConvNeXt / Swin / EfficientNet 共 15 个模型，弱增强，D4 TTA，贪心加权融合。OOF 0.9600，嵌套验证 0.9520。
- **task2 人脸表情识别**：多架构成员池，伪标签迭代，对数概率加权集成。OOF 0.7417。
- **task3 黄斑中心凹定位**：ResNet18-FPN 热图回归，视盘通道，多尺度推理，7 模型坐标中位数。OOF 19.67 像素。
- **task4 视网膜血管分割**：U-Net，5 折交叉验证，级联精修器，按官方脚本编码 RLE。OOF Dice 0.8466。

## 复现

每个任务目录的 README 有完整命令。任务一可直接复现融合：

```bash
cd task1
python3 code/02_融合/reproduce.py --verify
```

数据与模型权重不入库，运行前按各任务 README 放回数据。任务一、二在 Kaggle T4/P100 上训练，任务三、四在本地 CPU 上训练。

比赛结束后训练与推理代码未改。
