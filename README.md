# 机器学习课程设计

《机器学习》课程设计包含四个 Kaggle 任务：植物幼苗分类、人脸表情分类、眼底黄斑中心定位、视网膜血管分割。本仓库按任务分目录整理实现代码、配置、关键日志与最终的提交文件，便于查阅实现细节和复现结果。

课程设计报告把四个任务各写成一章，仓库里的目录与报告的章节一一对应。

## 四个任务一览

| 目录 | 任务 | 数据 | 方法关键词 | 主要结果 | 报告章节 |
|---|---|---|---|---|---|
| `task1/` | 植物幼苗分类 | 训练 500 张（5 类，每类 100 张）、测试 378 张 | 迁移学习（ConvNeXt、Swin、EfficientNet，5 批共 15 个模型），弱增强训练，D4 八向 TTA，贪心加权融合 | 5 折 OOF Micro-F1 0.9600，嵌套验证 0.9520 | 第 1 章 |
| `task2/` | 人脸表情分类 | 训练 28275 张、测试 7065 张，48×48 灰度，6 类 | 多骨干多分辨率训练，伪标签迭代，贪心加爬山权重搜索，类别偏置校准 | 5 折 OOF 准确率 0.7417 | 第 2 章 |
| `task3/` | 眼底黄斑中心定位 | 训练 80 张（附 XML 框标注）、测试 20 张 | ResNet18 + FPN 热图回归，空间 softmax 交叉熵配 soft-argmax 坐标损失，多尺度推理，视盘锚点通道，7 模型坐标中位数集成 | 公榜 RMSE 11.99623 | 第 3 章 |
| `task4/` | 视网膜血管分割 | 训练 20 张、测试 20 张，Dice 评价，RLE 提交 | U-Net 分割，BCE + soft Dice，5 折，级联精修器，阈值扫描 | 20 图 OOF 512-Dice 0.8453（阈值 0.45），精修器 0.8466（阈值 0.40），公榜 Dice 0.85729 | 第 4 章 |

报告文件：机器学习课程设计报告_祁震淼_20245627.docx / .pdf。

## 环境

代码在 Linux 下用 Python 3.10 运行，单卡 NVIDIA GPU。主要依赖：

```
torch torchvision timm
numpy pandas scikit-learn
opencv-python pillow
kaggle
```

各任务的依赖略有差别，训练脚本只用到上面这些库。GPU 显存需求由数据规模决定，task1 和 task2 的训练显存在 8 GB 以上即可，task3 和 task4 的输入图像较大，建议 16 GB 以上。

## 数据与权重的说明

比赛数据、模型权重、中间概率文件体积大，没有放入仓库。运行前需要把数据按各任务 README 的说明放回对应目录。仓库只保留能够用纯文本或小体积 CSV 表达的部分：配置、日志、指标和最终提交文件。

`task1/inputs/` 下保留了体积很小（每个 10 KB 左右）的折外概率与测试概率数组，`task2/data/ytr.npy` 是训练标签数组。这些文件是复现融合结果的直接输入，不属于原始图像数据。

## 复现方式

每个任务的 README 给出完整的命令序列。整体流程一致：先放好数据，训练若干模型，再按融合脚本生成提交。融合步骤可以在只读日志和已保存概率的前提下单独重跑，例如：

```bash
cd task1
python3 code/02_融合/reproduce.py            # 从 inputs/ 复现 submission.csv
```
